6. Підключення JavaScript, внесення змін та відправка до репозиторію

Було виконано підключення JavaScript та перевірку стилів:

  • index.html: підключено зовнішній файл скрипта тегом <script src="script.js"></script> у тілі документа <body>: 
    <!DOCTYPE html>
<html>
<head>
<title>Hello World!</title>
<link rel="stylesheet" href="style.css">
</head>
<body>
<script src="script.js"></script>

<h1>Hello world!</h1>
<p>This is the first file in my new Git Repo.</p>

</body>
</html>
  • script.js: містить вивід тестового повідомлення у консоль браузера: 
    console.log("Hello World!");
  • style.css: задає фоновий колір сторінки: 
    *{
background: green;
}

Фіксація та публікація змін у віддаленому репозиторії ppprrr111:

git add index.html script.js style.css
git commit -m "Замінено файли на власні версії index.html, script.js, style.css"
git push origin main

У результаті всі оновлені файли успішно опубліковано у гілці main репозиторію qavalliere/ppprrr111.

📷 Скріншот 6: Виконання commit та push змін
(Термінал з результатом виконання команд git commit та git push origin main)
